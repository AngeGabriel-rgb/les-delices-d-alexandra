
# KRE Shop - Boutique de Vêtements

## 🌟 Description

KRE Shop est une application vitrine moderne et élégante pour une boutique de vêtements proposant des collections pour hommes et femmes. L'application présente un design responsive et professionnel avec une palette de couleurs sophistiquée.

## 🎨 Palette de couleurs

- **Violet principal** : #7D4FFE
- **Lavande** : #D7AFFF  
- **Rose clair** : #FFB3D9
- **Rose vif** : #FF6F7F

## ✨ Fonctionnalités

### 🏠 Page d'accueil
- Bannière hero avec carrousel d'images automatique
- Navigation fluide et responsive
- Design moderne avec animations

### 📖 Section À propos
- Présentation de la boutique
- Statistiques et chiffres clés
- Images de présentation

### 🖼️ Galerie de produits
- Grille responsive de produits
- Modal de détails pour chaque produit
- Effets de survol et animations
- Catégorisation par genre

### 📞 Section Contact
- Formulaire de contact interactif
- Informations de contact détaillées
- Horaires d'ouverture
- Validation de formulaire avec notifications

### 🌐 Réseaux sociaux
- Liens vers Facebook et Instagram
- Icônes sociales dans le footer
- Intégration des réseaux sociaux

## 🛠️ Technologies utilisées

- **React 18** - Framework frontend
- **TypeScript** - Typage statique
- **Tailwind CSS** - Framework CSS utilitaire
- **Vite** - Outil de build moderne
- **Lucide React** - Icônes SVG
- **shadcn/ui** - Composants UI
- **React Query** - Gestion des données

## 📱 Responsive Design

L'application est entièrement responsive et s'adapte parfaitement à :
- 📱 Smartphones (320px et plus)
- 📱 Tablettes (768px et plus)  
- 💻 Ordinateurs de bureau (1024px et plus)
- 🖥️ Grands écrans (1440px et plus)

## 🚀 Installation et démarrage

### Prérequis
- Node.js (version 16 ou supérieure)
- npm ou yarn

### Installation
```bash
# Cloner le repository
git clone <votre-repository-url>

# Naviguer dans le dossier
cd kre-shop

# Installer les dépendances
npm install

# Démarrer le serveur de développement
npm run dev
```

L'application sera accessible sur `http://localhost:8080`

## 📦 Scripts disponibles

```bash
# Démarrage en mode développement
npm run dev

# Build de production
npm run build

# Prévisualisation du build
npm run preview

# Linting du code
npm run lint
```
